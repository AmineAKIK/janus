## Liste 1 : éléments NON DÉDUCTIBLES et RECOPIÉS

NON DÉDUCTIBLES : aucun au sens strict. Fragilités :

- B11-K2 : la question ne dit pas quelle version Farid a installée ; je ne peux écrire que « x64 ou arm64 selon son installation ».
- PR1-12 (page de l'IA relue deux fois) : la règle « relue ne suffit pas » n'est écrite qu'indirectement (ET9 dit « retouchée après coup » ; ET3 propose « relu une fois » comme mauvaise réponse sans l'expliquer). Je l'ai déduite.
- B11-K6 : le texte dit que le langage « dit quel IDE existe », mais n'écrit pas ce qu'on fait quand on n'a que l'IDE d'un autre langage ; j'ai répondu par le choix PhpStorm ou VS Code.
- B11-T2 : la question ne donne pas l'architecture du PC prêté ; je ne peux dire que « celle qu'on lit sur lui ».

RECOPIÉS (réponse écrite presque telle quelle dans le texte ou dans le « Pour lire » de la question) :

- PR1-5 : chaque association est écrite dans le « Pour lire » de la question (bouton d'aperçu, menu Terminal, palette).
- PR1-1, PR1-13 (conversion processeur ARM vers ARM64) et B11-Q2 (« arm64 en minuscules ») : la règle est redonnée dans la question, avec les mêmes cas que ET4.
- B11-R1, B11-C1, B11-T3, B11-K8 : même cas que « Ton pari, corrigé » avec un autre langage ; la règle est écrite (ET7 : « installer l'une n'installe pas l'autre »), mais ce n'est qu'un changement de nom.

## Liste 2 : mots employés par les questions que le texte ne définit jamais

- WSL (dans « Ubuntu (WSL) ») : jamais défini ; je sais seulement que c'est le nom du profil pour bash.
- « mode non commercial » : défini comme voie gratuite pour apprendre ou projet personnel, mais « projet personnel » n'est pas délimité (le site du magasin des parents de B11-R4 est-il personnel ou commercial ?).
- « Universal », « User Installer », « Apple silicon » : nommés, jamais expliqués.
- « outils du langage » (IDE) : cité, jamais défini.
- « serveur local » (ET12 La suite) : jamais défini.
- « convention » : « par convention, le terminal intégré s'ouvre dans le projet » ; le mot n'est pas défini (ET8 dit seulement « un fait à connaître »).
- « abonnement » est défini ; « édition » (Community) l'est seulement par « version gratuite » dans ET3.
- « suite de lettres et de chiffres » (2e ligne de code --version) : jamais dit ce que c'est.
