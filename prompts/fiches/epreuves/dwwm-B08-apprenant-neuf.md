PR1-3 : déductible (ET5 Prouver la version) : Non ; VERSION 1 veut dire WSL 1, qui traduit sans noyau Linux ; Running dit seulement que la distribution tourne.
PR1-4 : déductible (ET7 update puis upgrade ; Installer, lister, retirer) : install jq = installe le paquet jq ; list = affiche les paquets installés avec Homebrew ; uninstall jq = retire jq ; upgrade = met à jour les paquets installés ; update = met à jour Homebrew et sa liste, sans changer les paquets.
PR1-5 : RECOPIÉE (ET6 Les lignes « Next steps ») : la ligne qui rend le PATH bon tout de suite est la troisième (eval "$(/opt/homebrew/bin/brew shellenv)") ; celle qui écrit la commande dans .zprofile est la deuxième (echo 'eval ...' >> /Users/farid/.zprofile) ; ce sont les mêmes lignes que l'exemple.
PR1-6 : déductible (ET7 Deux commandes en une ligne) : la troisième ne part pas, car chaque && relie la commande qui le suit à celle qui le précède, et la deuxième a échoué.
PR1-7 : déductible (ET7 update, puis upgrade, tableau) : celle d'avant ; brew update n'actualise que Homebrew et sa liste, c'est upgrade qui met à jour les paquets.
PR1-8 : déductible (ET6 Un Mac est déjà UNIX ; ET7 Le gestionnaire) : la commande échoue ; le Mac reste macOS, Homebrew n'ajoute pas de système, apt est le gestionnaire d'Ubuntu et brew celui du Mac.
PR1-9 : déductible (ET6 D'où vient la ligne) : il ne la lance pas ; il prend la commande sur brew.sh ; un nom qui ressemble et le https/cadenas ne prouvent pas que le script est celui de Homebrew.
PR1-10 : déductible (ET7 sudo) : elle cherche d'abord ce que fait la commande ; on ne met pas sudo devant une commande qu'on ne comprend pas, ni parce qu'un site le demande.
B08-R1 : déductible (ET1 ; ET5 ; ET6 ; ET7) : Windows : terminal en administrateur, wsl --install, redémarrage, création de l'utilisateur Linux, wsl -l -v (VERSION 2), puis dans Ubuntu sudo apt update puis sudo apt install jq ; Mac : commande de brew.sh, lignes « Next steps », nouveau terminal et which brew, puis brew update puis brew install jq ; différence : Windows doit d'abord installer un shell UNIX (WSL 2/Ubuntu, apt, sudo), le Mac est déjà UNIX et n'a qu'à ajouter Homebrew (brew, sans sudo).
B08-R2 : déductible (ET7 update, puis upgrade) : non, update n'a fait qu'actualiser la liste des paquets ; pour mettre à jour elle tape sudo apt update puis sudo apt upgrade (ou les deux reliées par &&), la liste d'abord.

B08-R4 : déductible (ET6 D'où vient la ligne ; which brew dans un nouveau terminal) : il ne la lance pas, car elle ne vient pas de brew.sh et le script s'exécute avec ses droits ; il prend la ligne de brew.sh, puis dans un nouveau terminal tape which brew et obtient un chemin (/opt/homebrew/bin/brew).
B08-R5 : déductible (ET5 Un terminal en administrateur ; ET7 sudo) : dans les deux cas elle exécute avec des droits d'administrateur, pour modifier le système (Windows, ou Ubuntu pour tous ses utilisateurs) ; une commande qu'elle ne comprend pas, elle ne met pas sudo devant et cherche d'abord ce qu'elle fait.
B08-Q1 : déductible (ET4 Le shell et son invite) : c'est le shell PowerShell, qui lit les lignes derrière la fenêtre (le terminal) ; elle l'a reconnu à l'invite PS C:\Users\...>.
B08-Q2 : déductible (ET4 UNIX) : Linux (donc Ubuntu) et macOS sont de la famille UNIX, Windows non ; le Mac a déjà un shell UNIX (zsh), le PC doit installer un système UNIX, Linux, via WSL 2 avec Ubuntu.
B08-Q3 : déductible (ET4 Linux, noyau, Ubuntu) : Linux Mint est une distribution Linux (noyau Linux plus des outils choisis par ses auteurs), comme Ubuntu, qui emporte le même noyau.
B08-Q4 : déductible (ET5 Linux dans une machine virtuelle ; Prouver la version) : 1 = WSL 1, sans noyau Linux, qui traduit les demandes pour Windows ; la version 2 qu'elle veut fait tourner un vrai noyau Linux dans une machine virtuelle légère.
B08-Q5 : déductible (ET5 La virtualisation du processeur ; Quand l'installation échoue) : activer la virtualisation dans le BIOS ou l'UEFI (VT-x, AMD-V ou SVM), redémarrer, puis vérifier la fonctionnalité « Plateforme de machine virtuelle » et relancer wsl --install ; Hyper-V complet n'est pas nécessaire.

B08-Q7 : RECOPIÉE (ET7 Un paquet et son dépôt ; Le gestionnaire et les dépendances) : le paquet est le logiciel installable ; le dépôt est le serveur sur Internet qui tient les paquets et leur liste ; les dépendances sont les autres paquets dont le premier a besoin.
B08-Q8 : déductible (ET7 Deux commandes en une ligne) : non, tree ne s'installe pas, la seconde commande ne part que si la première a réussi ; cela évite d'installer à partir d'une liste non actualisée (même logique que pour upgrade).

B08-C3 : déductible (ET6 Un Mac est déjà UNIX) : faux, le Mac est déjà UNIX ; Homebrew ajoute un outil qui installe d'autres outils, pas un système.

B08-T3 : déductible (ET7 sudo ; ET4 Deux fenêtres) : sudo lance la commande avec les droits d'administrateur ; elle ne la tape pas avant de savoir ce qu'elle fait, et pacman n'est pas le gestionnaire d'Ubuntu (apt), donc elle cherche la bonne commande.
B08-K1 : déductible (ET4 Deux fenêtres, deux shells ; ET7) : non, c'est une invite zsh de Mac ; apt et sudo sont les commandes de bash dans Ubuntu, le gestionnaire du Mac est brew.
B08-K2 : déductible (ET5 Linux dans une machine virtuelle) : WSL 2 est une machine virtuelle légère qui tourne à côté de Windows avec son noyau Linux, en partageant processeur, mémoire et disque, donc Windows reste en marche.
B08-K3 : déductible (ET6 Les lignes « Next steps ») : eval ne règle le PATH que dans la fenêtre ouverte ; les deux echo n'ayant pas écrit la ligne dans .zprofile, un nouveau terminal ne connaît pas /opt/homebrew.

B08-K5 : déductible (ET7 tableau update/upgrade) : non ; wsl --update, dans une fenêtre de Windows ; sudo apt upgrade installe les versions plus récentes des paquets déjà installés dans Ubuntu.
B08-K6 : déductible (ET7 Deux commandes en une ligne) : sudo apt update && sudo apt upgrade ; plus sûre car si update échoue, upgrade ne part pas et ne travaille jamais sur une liste périmée.
B08-K7 : déductible (ET5 Un terminal en administrateur ; ET7 sudo) : dans Windows les droits viennent de la fenêtre ouverte en administrateur, dans Ubuntu de sudo devant une commande ; dans les deux cas ce sont des droits d'administrateur pour modifier le système, et on ne les utilise qu'en comprenant ce qu'on tape.
B08-K8 : déductible (ET7 Installer, lister, retirer, vérifier) : tree n'est pas installé ou son dossier manque au PATH ; brew list affiche les paquets installés avec Homebrew.
