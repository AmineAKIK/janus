PR1-3 : déductible (ET6 « Un usage commercial », « Modifier et partager », « Partager sous la même licence ») : CC BY-NC telle quelle : non, NC interdit l'usage commercial et le site d'une boutique en est un. CC BY-SA passée en noir et blanc : oui, en citant l'auteur et en partageant la version retouchée sous la même licence CC BY-SA.
PR1-5 : déductible (ET7 « MIT », « Apache 2.0 », « GPL et le copyleft » + règles données dans la question) : MIT copié tel quel : garder l'avis de copyright et le texte de la licence. Bibliothèque Apache avec deux fichiers modifiés : garder la licence et les mentions, reproduire le NOTICE, signaler les deux fichiers modifiés. Composant GPL dans un logiciel vendu : c'est une distribution, donc distribuer le logiciel sous la GPL avec son code source. Autre script MIT modifié de trois lignes : même chose que MIT, garder l'avis de copyright et le texte de la licence (la licence permet de modifier).
PR1-7 : déductible (ET8 « La licence d'une police », ET5 « Libre de droits ») : « Bois Sans » : oui, la licence permet le site web même commercial (on ne la revend pas seule, sans objet ici). « Plume » : non en l'état, « libre de droits » et « gratuite » ne disent rien de précis ; sans licence lue, aucune permission, il faut trouver la licence ou prendre une autre police. « Atelier » : non, la licence « poste de travail » ne couvre pas le site web, il faut acheter la licence « site web », vendue à part.
PR1-8 : déductible (ET5 « Les quatre raisons », « Les exceptions, une liste fermée », ET6 « La Licence Ouverte ») : tableau du peintre vivant : autorisation écrite (valable pour ce qu'elle dit, deux ans). Horaires des marchés de Valmoreau : licence (la Licence Ouverte, avec source et date de mise à jour). Photo copiée sur un blog, sans licence ni auteur identifié, pour décorer : aucune. Deux lignes d'un livre dans un article critique, avec nom et source : exception (courte citation).
PR1-4 : déductible (ET7 « Apache 2.0 ») : garder avec l'outil la licence et le NOTICE de la bibliothèque ; l'outil d'Inès reste sous MIT, Apache n'a pas de copyleft (rien à signaler comme modifié puisqu'elle n'a pas modifié la bibliothèque).
PR1-2 : déductible (ET5 « Le fair use n'existe pas en France ») : refuser. Le fair use est une règle américaine que le droit français ne connaît pas ; seules la liste fermée des exceptions ou une autorisation écrite (ou une licence, ou le domaine public) permettraient de reprendre le dessin ; citer le journal ou être petit n'y change rien. (Cas proche de l'exemple de l'explication, mais habillage différent.)
PR1-6 : déductible (ET9 « Mentions légales et confidentialité », « Le directeur de la publication », « L'hébergeur, toujours ») avec réserve : mentions légales : nom de la société, siège, téléphone ; nom, adresse et téléphone de l'hébergeur ; nom du directeur de la publication. Politique de confidentialité : durée de conservation des e-mails des clients (c'est ce que le site fait des données). Le droit d'effacement : je le classe en politique de confidentialité par élimination (ce n'est ni qui édite ni qui héberge), mais le texte n'écrit jamais que les droits des personnes y vont.
B17-R1 : déductible (ET4 « Droit moral, droits patrimoniaux ») : non. Elle a seulement reçu par cession le droit de reproduire le dessin (un droit patrimonial). Le droit moral (être nommé comme auteur, faire respecter l'œuvre) est perpétuel et ne se vend ni ne se cède : effacer la signature, c'est signer à la place de l'auteure, ce qu'elle peut interdire.
B17-R2 : déductible (ET4 « Soixante-dix ans ») : non, pas encore. Morte le 22 avril 1961 : décompte depuis le 1er janvier 1962, les 70 ans finissent le 31 décembre 2031, domaine public à partir du 1er janvier 2032. B17-R3 : déductible (ET4 « Le code d'Inès ») : non, pas sans rien demander. Une prestataire garde ses droits patrimoniaux ; sans cession écrite, la clinique n'a que l'usage que leur accord prévoit. Confier la suite du code à une autre agence (le modifier, le confier), c'est traiter le code comme le sien : il lui faut une cession écrite de la développeuse.
B17-R4 : déductible (ET5 « Les exceptions, une liste fermée », « Le fair use n'existe pas en France ») : illustrations pour décorer : rien ne le permet, le fair use n'existe pas en France et décorer ne figure pas dans la liste fermée des exceptions. Deux lignes du livre dans une critique, avec l'auteur et la source : permis, c'est la courte citation.
B17-R5 : déductible (ET6 « Citer l'auteur ») : « Bruits de pluie », Lou Maréchal, musiques-libres.example/pluie, CC BY 4.0, raccourcie par [nom du vidéaste] (mention de la modification, avec liens pour la source et la licence). B17-R6 : déductible (ET9 « L'hébergeur, toujours ») : non, incomplètes. L'éditeur (dénomination, capital, siège, téléphone, immatriculation) et le directeur de la publication y sont, mais l'hébergeur manque : son nom, son adresse et son téléphone sont obligatoires pour tout éditeur.
B17-Q1 : déductible (ET7 « MIT ») : il garde avec le composant l'avis de copyright et le texte de la licence MIT, même modifié de trois lignes ; la licence MIT ne dit rien de son propre code, il choisit librement la licence.
B17-Q2 : déductible (ET7 « Apache 2.0 ») : non. Apache ajoute une concession de brevet : chaque contributeur permet d'utiliser ses brevets pour son code et ne peut pas reprocher à celui qui s'en sert de l'employer.
B17-Q3 : déductible (ET7 « GPL et le copyleft ») : usage seule sur son ordinateur : rien n'est exigé. Au moment où elle donne le script modifié à sa collègue (distribution) : elle doit le distribuer sous la même licence GPL, avec le code source.
B17-Q4 : déductible (ET6 « La Licence Ouverte ») : mention de la source et de la date de dernière mise à jour, par exemple « Source : Métropole de Rivemont, horaires des déchetteries, mis à jour le 3 mars 2027 » (un lien suffit), sans laisser croire que la métropole soutient le site. Oui, un site privé peut les réutiliser, même pour un commerce.
B17-Q5 : déductible (ET8 « La licence d'une police ») : sur le site de la boutique : oui (site web et commerce permis). Vendre la police elle-même en téléchargement : non, la vente de la police seule est interdite.
B17-Q6 : RECOPIÉE (ET8 « Où lire la licence », dernier paragraphe) : non. Une phrase « libre, utilise-le comme tu veux » dans un fichier de présentation n'est pas une licence (elle ne dit ni qui permet ni à quelles conditions) ; sans LICENSE, aucune permission : demander une licence ou une autorisation écrite, ou prendre un autre script.
B17-C1 : déductible (ET6 « Citer l'auteur », « Un usage commercial », « Partager sous la même licence ») : « CC BY-SA 4.0 » telle quelle : oui, en citant l'auteur (SA ne joue que si on modifie). « CC BY-NC-ND 4.0 » : non, NC interdit l'usage commercial et le site d'une boutique en est un. « CC, c'est CC » est faux : chaque module ajoute une condition, il faut lire la combinaison.
B17-C2 : déductible (ET9 « L'hébergeur, toujours », « Trouver l'hébergeur ») : non, correcte pas : l'hébergeur figure toujours dans les mentions. Ordre : trouver l'adresse IP du site (nslookup ou outil en ligne), lire le WHOIS de cette adresse (champ organisation) ; si c'est un service de diffusion, ce n'est pas l'hébergeur, alors vérifier avec la facture ou le contrat de la société ou lui demander ; puis écrire nom, adresse et téléphone de l'hébergeur.
B17-C3 : déductible (ET4 « Le code d'Inès ») : composant du salarié, écrit dans ses fonctions : oui, les droits patrimoniaux reviennent à l'employeur. Composant de l'indépendante sans écrit : non, elle garde ses droits, il faut une cession écrite qui délimite l'usage ; sans elle, la société ne peut pas vendre le logiciel entier.
B17-T1 : déductible (ET5 « Libre de droits », « Les quatre raisons », « Le fair use n'existe pas en France ») : erreur 1 : « libre de droits » n'est pas un statut, il ne dit pas qu'elle est utilisable partout ; il faut lire si elle est du domaine public, sous licence ou sous autorisation écrite. Erreur 2 : citer ne suffit pas, ce n'est pas une des quatre raisons ni une exception ; sans raison, on n'utilise pas l'œuvre.
B17-T2 : déductible (ET7 « Apache 2.0 », « GPL et le copyleft ») : avec Apache : garder la licence et le NOTICE, signaler les fichiers modifiés (aucun ici), son code fermé peut rester fermé. Avec GPL : le logiciel qui contient du code GPL, vendu donc distribué, doit l'être sous la GPL avec son code source : le code ne peut plus rester fermé.

B17-K1 : déductible (ET4 « Protégée dès la création ») : oui, protégée dès sa création si elle est originale (cadrage, lumière : des choix libres), sans dépôt ni ©. B17-K3 : déductible (ET4 « Soixante-dix ans ») : morte le 8 octobre 1975 : décompte depuis le 1er janvier 1976, les 70 ans finissent le 31 décembre 2045, domaine public à partir du 1er janvier 2046.

B17-K10 : déductible (ET6 « Citer l'auteur ») : non. L'attribution se place à un endroit visible : légende sous l'image, ou page « Crédits » avec un lien en bas de chaque page où l'image apparaît ; un fichier au fond du code, que les visiteurs ne voient jamais, ne suffit pas.
