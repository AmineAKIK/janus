# Grille de la méthode : B01, version 8

Bloc de type système : le schéma (bit, octet, ce qui lit, convention de lecture, sens) porte le bloc ; les conversions, que l'objectif demande à la main puis avec aisance, s'entraînent en pratique (ET9) et sur plusieurs jours (ET10). Les étapes, dans l'ordre : ET1 perception, ET2 carte, ET3 pré-test, ET4 à ET8 explication, ET9 pratique, ET10 aisance, ET11 ensemble, ET12 restitution, ET13 consolidation, ET14 bilan.
