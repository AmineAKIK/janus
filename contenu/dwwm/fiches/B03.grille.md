# Grille de la méthode : B03, version 1

Bloc de type système : le schéma (le stockage garde, même éteint ; au lancement, ce qu'il garde est copié dans la RAM, qui tient prêt ce qui tourne ; le processeur l'y lit, par son cache, et l'exécute ; la carte graphique dessine l'image, que l'écran affiche) porte le bloc. Les savoir-faire de l'objectif (choisir la version d'un logiciel, relever sa machine, diagnostiquer une lenteur, juger une machine pour développer) s'entraînent dans le cours et en pratique (ET13, dont deux items sur la machine de l'apprenant). Les étapes, dans l'ordre : ET1 perception, ET2 carte, ET3 prétest, ET4 à ET12 explication, ET13 pratique, ET14 ensemble, ET15 restitution, ET17 bilan. Un cas porte le cours : le portable de Yasmine, 34 ans (disque dur de 1 To, affiché 931 Go ; 8 Go de RAM, un emplacement libre sur deux ; Intel Core i5 à 4 cœurs, 1,6 GHz de base, L3 de 6 Mo ; x64 ; carte graphique intégrée), avec Windows à 3 000 Mo, VS Code à 1 000 Mo et 150 Mo par onglet. Chaque étape d'explication s'ouvre sur ce portable ; les autres cas ont chacun un prénom et les mêmes données partout (Farid et Lucie, Mac M2 et M3 ; Thomas, PC Windows ARM ; Mehdi, 8 Go en 2 sur 2 ; Clara ; Bilal ; Anaïs, Ryzen 5 ; Nadia ; Rayan, 19 ans). Les conventions dont un écran se sert sont dans un encadré « …, pour lire : », au-dessus de l'exercice ; la consigne ne garde que la situation et la question.
