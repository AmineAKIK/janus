# Les cahiers de conception

Un cahier par fiche, écrit avant la fiche (étape 2 du mode d'emploi `.claude/skills/fiche/SKILL.md`) : l'identité du bloc, ses erreurs critiques en phrases d'apprenant, le modèle du bloc (éléments, relations typées, relation centrale, frontières, à quoi il sert), le fil rouge, le parcours étape par étape dans l'ordre du cycle, le manifeste, le tableau d'alignement, les contraintes de style, les classes de défaut des blocs précédents, et ce que l'auteur rend.

Le cahier suivant se calque sur le dernier. Il ne cite aucun chemin d'une session : ce qu'il nomme est dans le dépôt, ou se produit avec une commande du dépôt. Les tâches réservées à l'évaluation et le champ `diagnostic` du plan détaillé n'y entrent jamais.

B05 et B06 ont été écrits avant que ce dossier existe ; leurs cahiers sont repris ici tels qu'ils ont servi, les chemins de session remplacés par leur équivalent dans le dépôt.
